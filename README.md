# Discord Multi-Bot Music System

Discord 음성 채널을 위한 고성능 다중 봇 음악 재생 시스템입니다.  
YouTube, Spotify, Apple Music, Melon 등 주요 음원 플랫폼의 메타데이터를 통합 지원하며, 단일 컨트롤러 메시지 실시간 갱신(In-place Update), 1초 단위 실시간 재생 진행률 추적, 다중 봇 풀(Multi-Bot Worker Pool) 아키텍처를 기반으로 설계되었습니다.

---

## 1. 시스템 주요 기능

### 다중 봇 풀 매니저 (Multi-Bot Worker Pool)
- 단일 프로세스 내에서 복수의 Discord 봇 토큰을 동시에 초기화하고 관리합니다.
- 서버 내 서로 다른 음성 채널에서 `/재생` 명령어가 실행될 경우, 유휴 상태인 보조 봇을 동적으로 배정하여 복수 채널 동시 재생을 지원합니다.
- 특정 채널에 이미 배정된 봇은 해당 채널의 전용 세션으로 보호되며, 다른 채널의 명령어가 개입하지 못하도록 분리됩니다.

### 단일 컨트롤러 메시지 In-place 갱신
- 신규 곡 재생, 일시정지, 곡 건너뛰기, 대기열 점프 등 상태가 변경될 때 신규 메시지를 전송하지 않고 기존 컨트롤러 메시지를 직접 수정(Edit)합니다.
- 음성 채널 퇴장 시 기존 컨트롤러의 대형 썸네일, 임베드, 버튼을 완전히 제거하고 단일 퇴장 안내 텍스트로 전환하여 채팅창의 가독성을 보존합니다.

### 1초 단위 실시간 재생 진행률 갱신 및 API 최적화
- 1초 주기로 타임바, 현재 경과 시간, 잔여 시간을 계산하여 컨트롤러 메시지에 반영합니다.
- 재생 위치가 변경되지 않은 프레임은 Discord API 요청을 생략하여 불필요한 네트워크 트래픽을 차단합니다.
- Discord API Rate Limit(HTTP 429) 발생 시 응답 헤더 기반 백오프 대기를 수행하여 안정적인 메시지 갱신을 보장합니다.

### 통합 메타데이터 리졸버 (Multi-Platform Resolver)
- **YouTube**: 단일 영상 URL, 키워드 검색, 재생목록(`list=` 파라미터) 자동 감지 및 일괄 대기열 등록을 지원합니다.
- **Spotify**: 트랙 URL로부터 `__NEXT_DATA__` 및 oEmbed를 파싱하여 메타데이터를 추출한 뒤 최적의 음원을 매칭합니다.
- **Apple Music**: Schema.org JSON-LD 및 OpenGraph 메타데이터를 분석하여 음원을 식별합니다.
- **Melon**: 멜론 곡 고유 식별자(`songId`)를 기반으로 곡명 및 아티스트를 크롤링하여 스트림과 연동합니다.

### 대기열 관리 및 텍스트 파일 내보내기
- 대기열이 10곡 이하인 경우 임베드 내에 전체 목록을 표시합니다.
- 대기열이 10곡을 초과하는 경우 상위 10곡만 임베드에 노출하고, 11번째 곡부터 전체 대기열 정보(순번, 곡명, 아티스트, 플랫폼, 원본 URL)를 담은 `대기열_목록.txt` 파일을 자동 생성하여 첨부합니다.
- 대기열 선택 드롭다운 메뉴를 통해 원하는 곡으로 즉시 점프하여 재생할 수 있습니다.

### 상세 곡 정보 및 제어 (Info Panel)
- 컨트롤러의 Info 버튼 클릭 시 텍스트 프로그레스 바와 함께 상세 제어 패널이 표시됩니다.
- 0%부터 80%까지 20% 단위로 지정할 수 있는 타임바 위치 선택 드롭다운을 제공합니다.
- `-30초`, `+30초` 탐색 버튼 및 초 단위 직접 이동 모달을 지원합니다.
- YouTube 영상의 경우 상위 인기 댓글 5개를 추출하여 출력하는 기능을 포함합니다.

### 세션 보안 및 유휴 리소스 회수
- `/재생` 명령어 실행 시 선택적으로 세션 비밀번호를 설정할 수 있습니다. 비밀번호가 설정된 세션에서는 일반 사용자의 버튼 조작이 잠기며, 모달을 통한 1회 인증 또는 서버 관리자 권한을 가진 사용자만 제어할 수 있습니다.
- 모든 대기열의 재생이 종료되거나 일시정지 상태가 3분간 지속될 경우 유휴 타이머가 동작하여 자동으로 음성 채널에서 퇴장하고 세션 메모리를 초기화합니다.

## 2. 프로젝트 구조

```
Song_Bot/
├── api/
│   ├── __init__.py         # 외부 API 통합 인터페이스
│   ├── apple_music.py      # Apple Music 메타데이터 파서
│   ├── melon.py            # Melon 웹 크롤러 및 메타데이터 파서
│   ├── resolver.py         # 플랫폼 판별 및 음원 변환 리졸버
│   ├── spotify.py          # Spotify 트랙 메타데이터 파서
│   └── youtube.py          # YouTube 스트림 추출, 재생목록, 검색, 댓글 모듈
├── bot.py                  # 멀티 봇 풀, 재생 상태 머신, 인터랙티브 UI 메인
├── requirements.txt        # 의존성 패키지 명세
├── README.md               # 프로젝트 사양 및 실행 가이드
├── .env.example            # 환경 변수 템플릿 파일
└── .env                    # 환경 변수 설정 파일 (로컬)
```

## 3. 사전 요구사항

- Python 3.10 이상
- FFmpeg (시스템 PATH에 등록되어 있거나 로컬 디렉터리에 실행 파일 배치)

---

## 4. 설치 및 환경 설정

### 1) 의존성 패키지 설치
```powershell
pip install -r requirements.txt
```

### 2) 환경 변수(.env) 설정
프로젝트 루트 디렉터리에 `.env` 파일을 생성하거나 수정합니다.

```env
# 단일 봇 운영 시
DISCORD_TOKEN=your_primary_bot_token_here

# 2대 이상의 다중 봇 풀 운영 시 (각 음성 채널 동시 재생 지원)
DISCORD_TOKEN_2=your_secondary_bot_token_here
DISCORD_TOKEN_3=your_third_bot_token_here

# 또는 쉼표(,)로 구분된 일괄 토큰 지정
# DISCORD_TOKENS=token_1,token_2,token_3

# 커스텀 FFmpeg 실행 경로 (필요 시 지정, 미지정 시 시스템 PATH 또는 자동 감지)
# FFMPEG_PATH=C:\ffmpeg\bin\ffmpeg.exe
```

## 5. 실행 방법

다음 명령어를 통해 봇 풀을 실행합니다:

```powershell
python bot.py
```

실행 시 `discord.utils.setup_logging(level=logging.INFO)`에 따라 터미널에 표준 연결 및 준비 로그가 실시간 출력됩니다:

```text
2026-10-16 20:00:47 INFO     discord.client logging in using static token
2026-10-16 20:00:49 INFO     discord.gateway Shard ID None has connected to Gateway (Session ID: ...).
2026-10-16 20:00:50 INFO     discord.client 봇 로그인 완료: BotName (봇 1호기 준비됨)
```

## 6. 명령어 및 UI 인터페이스 사양

### 슬래시 명령어
- `/재생 query:<검색어 또는 URL> [password:<세션 비밀번호>]`
  - 음원 검색 키워드 또는 YouTube, YouTube 재생목록, Spotify, Apple Music, Melon URL을 입력하여 재생합니다.
  - 비밀번호를 지정할 경우 해당 세션의 제어 버튼 조작 권한이 제한됩니다.

### 컨트롤러 버튼 구성
- **곡 추가**: 모달 입력창을 호출하여 현재 대기열에 단일 곡 또는 재생목록을 추가합니다.
- **중지 / 재생**: 오디오 재생 및 일시정지 상태를 토글합니다.
- **곡 건너뛰기**: 현재 곡을 즉시 중단하고 다음 대기열의 곡을 재생합니다.
- **Info**: 현재 재생 곡의 타임바, 구간 점프, Seek 모달 및 YouTube 댓글 조회 뷰를 호출합니다.
- **대기열**: 현재 대기열 목록을 조회하며, 10곡 초과 시 텍스트 파일을 첨부하고 드롭다운 점프를 제공합니다.
- **퇴장**: 오디오 스트림 및 음성 연결을 강제 해제하고 컨트롤러 메시지를 퇴장 완료 상태로 갱신합니다.

실행 시 `discord.utils.setup_logging(level=logging.INFO)`에 따라 터미널에 표준 연결 및 준비 로그가 실시간 출력됩니다:

```text
2026-10-16 20:00:47 INFO     discord.client logging in using static token
2026-10-16 20:00:49 INFO     discord.gateway Shard ID None has connected to Gateway (Session ID: ...).
2026-10-16 20:00:50 INFO     discord.client 봇 로그인 완료: BotName (봇 1호기 준비됨)
```
